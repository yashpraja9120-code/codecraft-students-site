How Neural Networks Actually Work (Explained Simply)

Forget the brain metaphors for a minute — here's what a neural network is actually computing, step by step, with a tiny worked example.

2026-03-01 · 9 min read · ai, neural-networks

Set the brain metaphor aside

Neural networks are usually introduced with a "modeled after the brain" comparison. It's true at a very loose, historical level, but it tends to obscure what's actually happening, which is closer to repeated arithmetic than biology. Here's the version without the metaphor.

The basic unit: a weighted sum

A single artificial "neuron" takes several numeric inputs, multiplies each by a number called a weight, adds them together with a bias term, and passes the result through a function that decides the neuron's output. That's the entire computation.

output = activation(w1*x1 + w2*x2 + w3*x3 + bias)

The weights and bias are the numbers the network "learns." Everything about training a neural network is really just repeatedly adjusting these weights and biases so the network's output gets closer to correct.

Why the activation function matters

Without an activation function, stacking layers of weighted sums would collapse into one big weighted sum — no more powerful than a single layer. Functions like ReLU (which simply outputs zero for negative values and passes positive values through unchanged) introduce non-linearity, which is what lets networks model complex, curved relationships in data instead of only straight-line ones.

A tiny worked example

Say we want a network to guess whether a fruit is a lemon based on two inputs: sourness (0–10) and yellowness (0–10).

sourness = 8
yellowness = 9

w_sourness = 0.4
w_yellowness = 0.5
bias = -6

score = (w_sourness * sourness) + (w_yellowness * yellowness) + bias
# score = 3.2 + 4.5 - 6 = 1.7

# a simple activation: if score > 0, predict "lemon"
prediction = "lemon" if score > 0 else "not lemon"

Before training, the weights (0.4, 0.5) and bias (-6) would start out as small random numbers producing mostly wrong guesses. Training adjusts them, example by example, until predictions like this one are usually correct.

How layers build on this

A real network stacks many of these units into layers: an input layer (the raw data), one or more hidden layers (where the actual pattern-finding happens), and an output layer (the final prediction). Each neuron in one layer connects to every neuron in the next, each connection carrying its own weight. "Deep learning" simply refers to networks with several hidden layers.

How the weights actually get adjusted

After a prediction, the network measures how wrong it was using a loss function. An algorithm called backpropagation then calculates how much each individual weight contributed to that error, and gradient descent nudges each weight slightly in the direction that would have reduced the error. Repeat this over thousands of examples, and the weights gradually converge on values that make good predictions.

The honest summaryA neural network is a large number of weighted sums, chained together and adjusted through repeated trial and error, until the combination reliably maps inputs to correct outputs. Nothing about it requires the network to "understand" what a lemon is.
